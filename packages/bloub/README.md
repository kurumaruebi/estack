# bloub (vendored)

The bot avatar of estack: one SVG shape morphing through its states, with a felt-plush variant.

Vendored from the MIT-licensed bloub package by Jérémy Perret, version 0.6.5
(homepage: https://bloub-app.pages.dev), with this repository's frame-rate patch applied.
See `LICENSE`. The vendored build is not published anywhere: import it as `@estack/bloub`
and `@estack/bloub/plush`. The public types are under `dist/package/types`.
