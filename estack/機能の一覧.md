# 機能の一覧（検証の地図）

検証のスキル（`.agents/skills/verify-estack/SKILL.md`）が、変えた所に合う行を探して確かめ方を決める。変えた所に行が無ければ、同じコミットで行を足す。

| 機能 | 主なファイル | 出る所 | 確かめ方 | 証拠 |
|---|---|---|---|---|
| 最初の画面（AI の選び方） | `src/renderer/src/features/onboarding/` | デスクトップ | verify-plan で snapshot（見出し「Build your AI team.」）と screenshot。利用データの共有のチェックが出ないことを見る | 画面写真 |
| エージェントの一覧と会話 | `src/renderer/src/features/agents/` | デスクトップ・iPhone | verify-plan でエージェントを開き、会話の欄に打って送る | 画面写真・画面の木 |
| 承認のカード（既定は先に聞く） | `packages/contracts/src/ipc-approvals.ts` `src/main/approval-automation-store.ts` | デスクトップ・iPhone | `bun run test:related src/main/approval-automation-store.test.ts`。画面は持ち主が iPhone で見る | 試験の名前 |
| iPhone とのつなぎ（Mobile Connect） | `packages/contracts/src/mobile-connect.ts` `apps/mobile/src/features/auth/` | iPhone | 試験 `apps/mobile/src/features/auth/` と `packages/contracts`。実機は持ち主が Expo Go で開く | 試験の名前・持ち主の確認 |
| アカウントの仕組み（開発用） | `apps/auth-api/` | VPS（ポート 3100） | `bun run test:api` | 試験の結果 |
| コメントと個人の値の検査 | `scripts/estack/check-comments.ts` `scripts/estack/check-personal.ts` | コミット前・CI | `bunx vitest run scripts/estack/` と、実際の悪い例で止まること | 検査の出力 |
| PR の流れ（依頼・作業係・マージ・反映） | `scripts/estack/coding*.ts` `scripts/estack/mac-worker.ts` `scripts/estack/queue-server.ts` `estack/bin/` | VPS・Mac・GitHub | `bunx vitest run scripts/estack/coding-jobs.test.ts`。通しは `estack/bin/coding request` で小さな依頼を出し、PR まで来るか見る。`estack/bin/coding report` で、依頼ごとの状態・PR・CI を一覧できる | PR の URL |
| Mac のコーディング用ユーザー | `estack/bin/setup-coding-user` `estack/bin/save-coding-token` `scripts/estack/mac-worker.ts` | Mac | 作業係のセッションの中で `whoami` が `estackcoder` を出すこと。`estackcoder` から持ち主のキーチェーンの鍵に届かないこと。セッションは自分でコミットする | コマンドの出力 |
| GitHub の読み取りの中継 | `scripts/estack/github-read-proxy.ts` | VPS | `curl -s http://127.0.0.1:3190/api/pulls?state=all` と、書き込みが 403 になること | curl の出力 |
| VPS の版ごとの一式（安定版・開発版） | `estack/bin/estack-instance` `estack/bin/deploy-vps` `estack/bin/check-metro` `estack/bin/install-vps-instance` `estack/vps/` | VPS | `estack/bin/install-vps-instance <版> --print` で差し込みを見る。`estack/bin/deploy-vps` の記録（`~/.cache/estack/deploy.log`）に「Deployed」と Metro の確かめが出ること | 記録の行 |
| モバイルのアプリ | `apps/mobile/` | iPhone | `bun run typecheck`。画面は持ち主が Expo Go で見る（作業係は iPhone を動かせない）。iPhone の Expo Go で開いて画面を見る | 持ち主の確認 |
