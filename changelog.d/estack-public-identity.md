### Changed

- Links and repository metadata now point at this repository's real GitHub home, and the CI badge matches the workflow that runs.
- The README no longer offers installer downloads or an in-app commercial checkout: this project publishes source only, for people who run their own server and build their own apps.
- The release process now describes what this repository does: a `v0.x.y` tag on `main` marks a stable point; no binaries, container images, or staged rollouts are published from here.
- The security contact and the code-of-conduct contact point at this project's maintainer.

### Removed

- References to the people and organization of the project this code started from are gone from the docs, issue templates, and package metadata, except for the attribution that the license requires in `LICENSE` and `NOTICE`.
- The contributor-agreement and automated-review process of the source project are no longer described, and `CODEOWNERS` no longer lists its maintainers. Outside pull requests are not accepted for now.
